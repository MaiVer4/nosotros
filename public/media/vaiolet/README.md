# Álbum de Vaiolet (Recién Nacida & Crecimiento)

Coloca aquí las fotos y videos de **Vaiolet** (`.jpg`, `.png`, `.webp`, `.mp4`, `.mov`, `.webm`) y luego ejecuta:

```bash
npm run scan:gallery
```

El script las convertirá automáticamente a WebP optimizado, generará sus miniaturas y las agregará al álbum de **Vaiolet** en la web.
